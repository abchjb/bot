# Pinterest2Eitaa Bot

ربات خودکار جستجوی ویدیوهای حجاب در Pinterest و ارسال به کانال ایتا با کپشن هوش مصنوعی.

## پیش‌نیازها

- حساب GitHub
- توکن ایتایار و Chat ID کانال

## راه‌اندازی

### قدم ۱: گرفتن توکن ایتایار

1. به https://eitaayar.ir بروید و ثبت‌نام کنید.
2. یک ربات بسازید و **توکن** را کپی کنید.
3. ربات را به کانال ایتا اضافه کنید (به عنوان ادمین).
4. **Chat ID** کانال را یادداشت کنید (مثلاً `@mychannel` یا `-100123456`).

### قدم ۲: ساخت مخزن GitHub

1. یک مخزن **عمومی** در GitHub بسازید (مثلاً `pinterest2eitaa`).
2. این فایل‌ها را آپلود کنید:
   - `main.py`
   - `requirements.txt`
   - `.github/workflows/bot.yml`
3. پوشه `.github/workflows/` را دقیقاً با همین ساختار بسازید.

### قدم ۳: تنظیم Secrets

در مخزن GitHub:
1. بروید به **Settings → Secrets and variables → Actions**
2. روی **New repository secret** کلیک کنید.
3. دو Secret بسازید:
   - `EITAA_TOKEN` → توکن ایتایار
   - `EITAA_CHAT_ID` → Chat ID کانال

### قدم ۴: تست دستی

1. بروید به تب **Actions** در مخزن.
2. روی workflow با نام **Pinterest2Eitaa Bot** کلیک کنید.
3. روی دکمه **Run workflow** بزنید.
4. چند دقیقه صبر کنید و لاگ را ببینید.

### قدم ۵: اجرای خودکار

بعد از تست موفق، هر ۶ ساعت یک بار به صورت خودکار اجرا می‌شود.

## تنظیمات

برای تغییر موضوع یا فرکانس، ویرایش کنید:

- **کلمات کلیدی:** در `main.py` متغیر `PINTEREST_KEYWORDS`
- **تعداد پست هر بار:** `MAX_POSTS_PER_RUN`
- **فرکانس:** در `bot.yml` مقدار `cron`
- **حداکثر حجم ویدیو:** `MAX_VIDEO_SIZE`

## عیب‌یابی

- اگر خطای `EITAA_TOKEN not set` دیدید → Secrets را چک کنید.
- اگر هیچ ویدیویی پیدا نشد → احتمالاً پینترست ساختار را تغییر داده؛ تابع `search_pinterest` را نیاز به بررسی دارد.
- اگر ارسال به ایتا خطا داد → Chat ID یا ادمین بودن ربات را چک کنید.

## هشدار

- فرکانس را کمتر از ۶ ساعت نکنید (خطر بلاک شدن GitHub).
- مسئولیت حق نشر محتوا با ادمین کانال است.
